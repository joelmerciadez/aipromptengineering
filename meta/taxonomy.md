# Taxonomy

Short glossary for categories and tags used in this library. Prefer existing terms before inventing new ones.

## Categories (folders)

| Folder | Use for |
| --- | --- |
| `coding` | Code review, debugging, refactoring, tests, docs-from-code |
| `writing` | Drafts, editing, tone, outlines, marketing copy |
| `research` | Summarization, comparison, literature-style synthesis |
| `productivity` | Planning, prioritization, meeting notes, workflows |
| `image` | Image / visual generation and editing prompts |
| `agents` | System prompts and multi-step agent playbooks |

## Common tags

| Tag | Meaning |
| --- | --- |
| `review` | Critique or checklist-style feedback |
| `refactor` | Improve structure without changing behavior |
| `debug` | Find and fix failures |
| `outline` | Structure before drafting |
| `edit` | Improve an existing draft |
| `summary` | Condense source material |
| `compare` | Contrast options or sources |
| `planning` | Break work into steps |
| `system` | Persistent agent / system instructions |
| `example` | Sample content for illustration |

## Frontmatter reminder

Every prompt file should include at least `title`, `description`, `tags`, and `author`. See [`CONTRIBUTING.md`](../CONTRIBUTING.md).
